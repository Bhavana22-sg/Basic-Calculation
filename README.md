# Basic-Calculation

🚀 Project Overview

The Basic Calculator is a simple C programming project that performs basic arithmetic operations on two user-provided numbers. The program uses a switch-case statement to perform addition, subtraction, multiplication, and division based on the user's choice. It also handles division by zero to avoid errors.

🎯 Objective

To develop a simple calculator using C programming.
To understand the use of switch-case statements.
To perform basic arithmetic operations.
To practice user input and output in C.

🛠️ Technologies Used

C Programming
Code::Blocks
GCC/MinGW Compiler

🔄 Project Workflow

Input Numbers → Select Operation → Switch-Case → Calculate → Display Result

📊 Result

The calculator successfully performs addition, subtraction, multiplication, and division and displays the correct result based on the user's choice.
